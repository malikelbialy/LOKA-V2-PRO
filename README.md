VIVA — Mixed Reality System on Android

A Kotlin/Android project for mixed reality:
- Back camera passthrough over digital windows
- Head tracking via device rotation sensors (3DoF)
- Hand tracking via MediaPipe (21 landmarks, pinch/drag detection)
- Voice assistant with wake-word "VIVA"
- Web pages rendered as 3D windows inside the scene
- AI assistant via Cloudflare Workers

See README.md for full documentation.
